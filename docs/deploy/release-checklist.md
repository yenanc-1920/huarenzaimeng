# 发布 Checklist

> 每次生产发布前，由 DevOps 负责人（小D）逐项确认。全部通过后方可触发生产部署。

---

## 1. 代码就绪

- [ ] feature 分支已合入 develop，CI 构建通过（绿色）
- [ ] develop → master PR 已创建，至少 1 人 Approve
- [ ] PR 中无 unresolved conversation
- [ ] 无 `TODO` / `FIXME` 遗留在关键路径

## 2. 测试验证

- [ ] 单元测试全部通过（`mvn test` 无失败）
- [ ] 核心链路 E2E 通过（充值下单 → 支付 → Reloadly → 订单完成）
- [ ] dev 环境已部署并验证（develop 分支自动构建产物）
- [ ] 回归测试：退款、风控、余额监控无异常

## 3. 数据库

- [ ] Flyway 迁移脚本已合入 `server/src/main/resources/db/migration/`
- [ ] 迁移脚本在 dev 环境已执行成功
- [ ] 迁移脚本可重放（幂等）
- [ ] 无破坏性 DDL（DROP COLUMN / DROP TABLE）或已确认数据备份

## 4. 环境变量 / 配置

- [ ] 新增环境变量已在云托管 dev + prod 环境配置
- [ ] 无硬编码密钥（grep 确认无明文 secret）
- [ ] Reloadly 生产密钥已就位（非沙箱）
- [ ] 微信支付商户证书有效期 > 30 天

## 5. 部署确认

- [ ] Docker 镜像已推送至腾讯云镜像仓库（tag = commit SHA）
- [ ] 镜像大小 ≤ 300MB
- [ ] 健康检查端点 `/actuator/health` 返回 UP
- [ ] 云托管最小实例数 ≥ 1（避免冷启动丢请求）

## 6. 回滚准备

- [ ] 上一版本镜像 tag 已记录（可一键回滚）
- [ ] 数据库回滚方案已确认（forward-fix 或版本切换）
- [ ] 回滚演练在最近 30 天内执行过

## 7. 灰度发布

- [ ] 灰度策略：1 实例 → 观察 30 分钟 → 全量
- [ ] 观察指标：错误率 < 1%、P99 延迟 < 2s、无 OOM
- [ ] 告警通道畅通（企业微信/钉钉 webhook 可收到通知）

## 8. 发布后

- [ ] 生产首笔健康检查通过
- [ ] 日志无 ERROR 级别异常（观察 10 分钟）
- [ ] 运营看板指标正常（订单量、成功率）
- [ ] 发布记录已更新（版本号、时间、变更摘要）
